Testing instructions

  1. Download and install the review build above.
  2. Launch Dan D Pak POS (Review). It connects to the review backend automatically.
  3. Log in with the test username & password supplied to Shopee in the app submission form.
  4. Open Bán Online (Online Sales) from the main menu.
  5. Go to Thiết lập kênh → Shopee and press Kết nối to test the one-click Shopee authorization (sandbox).
  6. Review Đơn hàng (Orders), Hàng hoá (Products / listing mapping), Tồn kho (Inventory) and Kết nối sàn (Marketplace Connections).

The review account is least-privilege: it can view and test the online-commerce and Shopee integration areas only. It cannot access secrets, production credentials, database administration, or destructive operations.
