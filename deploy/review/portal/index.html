Reviewer access

Log in with the test username and password provided to Shopee in the app submission form (they are not published on this page). The reviewer account is least‑privilege: it can view and exercise the online‑commerce and Shopee integration areas only, and cannot access secrets, production credentials, database administration, or destructive operations.

How to test the Shopee integration

  1. Use the Download button above and install the review build.
  2. Launch Dan D Pak POS (Review); it connects to the review backend automatically.
  3. Log in with the reviewer test credentials supplied in the submission form.
  4. Open Bán Online (Online Sales) from the main menu.
  5. Go to Thiết lập kênh → Shopee and press Kết nối to run the Shopee authorization (OAuth) against the sandbox.
  6. Review Đơn hàng (imported orders), Tồn kho (inventory view) and Kết nối sàn (marketplace connection status).

Scope note: this build authorizes a Shopee shop and reads orders/connection status in the sandbox. It does not publish products/listings, stock, or prices to Shopee.

Isolated environment: separate backend, synthetic seed data, and a reviewer role restricted to the review branch. No production database, credentials, or customer data are reachable from this instance.
